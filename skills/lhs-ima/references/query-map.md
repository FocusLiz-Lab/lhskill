## Output Discipline

- Report the knowledge base, queries, hits, evidence, and uncertainty.
- Do not expose IMA internal IDs.
- Do not fabricate source titles, dates, quotes, or transcript details.
- If retrieval fails, explain setup and ask the user to configure IMA instead of using local source folders.
